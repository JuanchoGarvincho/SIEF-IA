# SIEF-IA
# Plataforma Inteligente para la Evaluación de Ferias de Proyectos Académicos

Este proyecto consiste en un portal web integral diseñado para gestionar ferias de proyectos tecnológicos (electrónica, programación, etc.) en entornos universitarios. Su principal valor es la digitalización completa del proceso de evaluación, eliminando el uso de papel y permitiendo a los jurados calificar en tiempo real desde sus dispositivos móviles gracias a una interfaz responsive y la generación de códigos QR por cada proyecto.
